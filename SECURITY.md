# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/mattoddie/graphql-civil/security/advisories/new).
Do not open a public issue.

Include a description of the problem, the affected version and, if possible,
steps or input to reproduce it. You should receive a response within 7 days.
Once a fix is released, the advisory will be published and you will be
credited unless you prefer otherwise.
